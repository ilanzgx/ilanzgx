# Neovim Configuration

Personal Neovim configuration based on [AstroNvim v5](https://github.com/AstroNvim/AstroNvim).

## Features
- **Colorscheme:** Catppuccin Mocha with transparent background toggle (`<Leader>uT`)
- **Keymaps:** Buffer navigation, fast file picker, centered scrolling, visual mode line moving
- **LSP & Formatters:** TypeScript, Go, Lua, Python, Prettier, StyLua via Mason
- **File Explorer:** Neo-tree with dotfiles visible by default, plus Oil.nvim support
